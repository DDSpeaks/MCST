R22 production method
---------------------
1. Make recovery mode live only for the executing bounded exact-profile scan.
2. After any failed recovery, allow the next Watchdog retry to run normal RTTI
   discovery again.
3. Cache positive and negative normal-discovery results for 30 seconds so the
   recovery path cannot create continuous process-wide memory scans.
4. Preserve all configured Watchdog retry outcomes in the final diagnostic.
5. Use recent last-complete Tracker tables as Attention for the configurable
   stale_critical_after_minutes interval (default 10), then escalate to Critical.
6. Report Last Tracker attempt and Last complete snapshot separately.
7. Render Open Positions at an explicit 1100-pixel, 15-pixel-font table width
   inside a horizontal-scroll container.
