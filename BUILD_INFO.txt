R21 production method
---------------------
1. Read the Logs grid once, up to 200 non-empty rows.
2. Emit the first ten rows as the existing report-facing Recent Logs section.
3. Emit the full bounded set as the optional monitoring_logs section.
4. Let BrokerMonitor and LogAlertEngine use monitoring_logs while all visible
   reports remain limited to ten Recent Logs rows.
5. Process the monitoring rows oldest-to-newest so the newest Broker-specific
   connection or disconnection evidence determines the final state.
