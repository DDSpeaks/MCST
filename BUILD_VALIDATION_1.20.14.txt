MCST-Watchdog 1.20.14 - source validation, 27 September 2026
================================================================

Scope
-----
- Added the selected doctor-and-patient artwork as an embedded transparent PNG
  resource and draws it before the MCST-Watchdog name in the dashboard header.
- Preserved the compact native title bar with the descriptive version text
  "MCST-Watchdog 1.20.14 - MC16 + MC17 AutoTrading".
- The logo is packaged inside MCST-Watchdog.exe and requires no separate
  installed asset.
- Added an exact-fingerprint MC17 production AutoTrading profile for
  Charting.dll timestamp 0x6AB57EE6 and image size 18624512.
- Uses the dynamically verified MC17 strategy vtable RVA 0xB74CF0 and
  AutoTrading field offset 0x18.
- Preserved the verified MC16 production profile 0x6A5684BF / 18493440,
  RVA 0xA457B8 and offset 0x142 unchanged.
- Changed MultiCharts process discovery to accept only MultiCharts64.exe or
  MultiCharts.exe and to exclude the current Watchdog process explicitly.
- Release validation reads all inspected text files explicitly as UTF-8 so
  Windows PowerShell 5.1 preserves non-ASCII license and documentation text.
- Active INI validation excludes ignored build/output roots (`bin`, `obj`,
  `dist`, `.git`) while continuing to reject active INI files elsewhere.
- Added an ASCII-only Windows PowerShell 5.1 publication helper that uses the
  configured GitHub Desktop git.exe, runs validation before Git changes, and
  stops on every failed commit, push, tag, or remote-tag check.
- The helper normalizes only LICENSE to UTF-8 with BOM before validation. The
  copyright holder is assembled from Unicode code points, so the PS1 itself
  remains ASCII and cannot be misread by Windows PowerShell 5.1.
- Staged-diff checks use `git --no-pager`, avoiding the optional `less`
  executable that is not on PATH in some GitHub Desktop installations.
- Corrected the release-notes publication heading and gave that contract its
  own precise validation error.
- Retained Tracker Bridge V179 and Protocol V2 unchanged.

Research evidence
-----------------
- Five snapshots and four controlled transitions were captured on MC17.
- The selected MC17 field responded exactly in all 4/4 transitions.
- Both directions were verified: two 1->0 and two 0->1 changes.
- The selected field had zero unchanged or ambiguous transitions.
- No other candidate achieved a 4/4 full reverse-verified match.

Safety
------
- Both production profiles require an exact PE timestamp and image-size match.
- Header artwork loading is nonfatal; Watchdog remains operational without the
  image if Windows cannot decode the embedded resource.
- Unknown Charting.dll builds remain rejected and AutoTrading stays UNKNOWN.
- Monitoring remains passive and read-only; it does not click MultiCharts,
  send input, place orders, change AutoTrading, or write to MultiCharts memory.

Validation status
-----------------
- Static source, version, compatibility-profile, process-identity and package
  validation performed in the preparation environment.
- Windows Release x64 compilation and live MC17 production-count confirmation
  remain required before a public tagged release.
