MCST-Watchdog 1.21.4 - source validation, 30 September 2026
================================================================

Change scope
------------
- Corrected the Visual Studio C2672/C2737 error in the history visible-row
  calculation by converting both Win32 LONG coordinates to int.
- Added separate Latest Activity and Latest Emails tabs.
- Added session-long, bounded histories with mouse-wheel navigation.
- Added a Developer Tools tab only to the Developer build.
- Restyled ordinary Help to match the highlighted Developer Help control.
- Retains rounded click-to-read bubbles for long Activity and Email text.

History behavior
----------------
- Histories begin empty at application startup and are not persisted.
- Each history is bounded to 1,000 newest entries.
- Latest Emails records Watchdog send completions and failures only.
- The normal Release build has no Developer Tools tab or research controls.

Retained compatibility
----------------------
- Version 1.21.0 automatic MC16/MC17 compatibility validation is unchanged.
- Verified MC16 and MC17 profiles, Bridge V181 and Protocol V2 are unchanged.

Windows Release x64 and ReleaseDeveloper x64 builds plus a live interaction
test are still required.
