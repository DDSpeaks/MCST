MCST-Watchdog 1.21.8 - source validation, 1 October 2026
================================================================

Change scope
------------
- Replaced the five-pixel painted history marker with a native Windows vertical
  scrollbar for Latest Activity and Latest Emails.
- Added thumb dragging, line arrows, page-area navigation and thumb tracking.
- Expanded mouse-wheel handling to the history tabs as well as their content.
- Automatically hides the scrollbar when every current-session item fits.
- Moved compatibility information into its own narrow top strip.
- Added a full-width separator below that strip.
- Kept the logo, application name and overall-health headline together in the
  main header below the separator.
- Retained the exact shared horizontal center of the small compatibility dot
  and the larger overall-health dot.
- Shifted the update row, System Status rows, history panel and matching row
  menu controls down by 28 pixels to preserve alignment.
- Updated release validation to recognize the current tabbed, scrollable
  Activity/Email history implementation instead of obsolete pre-tab tokens.
- Retained the wider compatibility row, refined tab boundary and taller
  dashboard introduced in 1.21.6.
- Corrected the Visual Studio C2672/C2737 error in the history visible-row
  calculation by converting both Win32 LONG coordinates to int.
- Added separate Latest Activity and Latest Emails tabs.
- Added session-long, bounded histories with mouse-wheel navigation.
- Added a Developer Tools tab only to the Developer build.
- Restyled ordinary Help to match the highlighted Developer Help control.
- Retains rounded click-to-read bubbles for long Activity and Email text.

History behavior
----------------
- Histories begin empty at application startup and are not persisted.
- Each history is bounded to 1,000 newest entries.
- Latest Emails records Watchdog send completions and failures only.
- The normal Release build has no Developer Tools tab or research controls.

Retained compatibility
----------------------
- Version 1.21.0 automatic MC16/MC17 compatibility validation is unchanged.
- Verified MC16 and MC17 profiles, Bridge V181 and Protocol V2 are unchanged.

Windows Release x64 and ReleaseDeveloper x64 builds plus a live interaction
test are still required.
