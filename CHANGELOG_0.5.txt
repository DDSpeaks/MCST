MCST-Watchdog 0.5 - First Production Test
==========================================

Added
-----
- First native Windows Dashboard with a fixed, stable layout.
- Shared WatchdogSystemStatus model for Dashboard and status report.
- Automatic Bridge V155 Tracker snapshot refresh.
- Configurable retry count, timeout, delay and Dashboard refresh interval.
- Live Accounts, Open Positions and Recent Logs row counts.
- Explicit Healthy, Warning, Critical and Unknown states.
- Recent activity area.
- Process private-memory, handle-count and uptime display.
- Manual Dashboard-style status report generation.
- Raw Bridge snapshot diagnostic output.
- Automatically generated MCST-Watchdog.ini.

Preserved
---------
- Existing MCBridge protocol.
- Existing named-pipe client.
- Existing strict Tracker snapshot parsing and validation.
- Existing support for valid partial Bridge snapshots.

Not integrated yet
------------------
- AutoTrading production reader and threshold alert.
- Broker monitoring.
- Email sending and AlertEngine.
- Scheduled status reports.
- Heartbeat sending.

These appear as explicit non-green states instead of simulated success.
