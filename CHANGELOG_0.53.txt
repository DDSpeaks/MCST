MCST-Watchdog 0.53 - First Production Test

Changes from 0.52:
- Replaced the small upper-right overall status word with a prominent traffic-light indicator.
- Added fixed overall status texts:
    SYSTEM HEALTHY
    ATTENTION REQUIRED
    CRITICAL CONDITION
    INITIALIZING
- The traffic-light color and text use the same WatchdogSystemStatus overall state as the Dashboard rows and status report.
- Dashboard element positions remain fixed; status changes never reorder the view.
- Application, window title, README and default INI version updated to 0.53.

No Bridge protocol or production-reading changes were made.
