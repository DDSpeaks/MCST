MCST-Watchdog 0.54
===================

Dashboard continuity and usability update.

Changes
-------
- Added a fixed Last successful system update line with clock time and age.
- Dashboard refreshes the update age once per second without rereading MultiCharts.
- Dashboard window position, size and maximized state are saved to MCST-Watchdog.ini.
- Restored window placement is clamped to an available monitor work area.
- Added a practical minimum window size.
- Command buttons stay anchored to the bottom when the window is resized.
- Added double-buffered painting to reduce flicker during continuous use.
- Updated visible and configuration version numbers to 0.54.

No Bridge protocol or Tracker snapshot format changes. Bridge V155 remains compatible.
