MCST-Watchdog 0.56 - First Production Test
==========================================

- Integrated the first-generation Watchdog's passive production AutoTrading reader.
- Reads RTTI-verified CStrategyObject instances from MultiCharts process memory.
- Counts active AutoTrading strategies without clicking, activating windows, sending input, or writing process memory.
- AutoTrading status is GREEN when active count is at or above the INI minimum.
- AutoTrading status changes directly to RED when active count is below the minimum; there is no warning band.
- AutoTrading read failures remain UNKNOWN and are not misreported as zero active strategies.
- The configured check interval is used as a cache interval to avoid expensive memory scans on every Dashboard refresh.
- Overall system status now includes the AutoTrading state.
- Bridge V155 protocol and Tracker snapshot format are unchanged.
