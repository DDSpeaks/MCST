MCST-Watchdog 0.571 - AutoTrading Compatibility Diagnostics
===========================================================

- Adds an AT Diagnostics button to the Dashboard.
- Creates C:\Temp\MCST-Watchdog-AutoTrading-Compatibility-0.571.txt.
- Reports detected MC processes and visible window titles.
- Reports Charting.dll base, size and PE timestamp.
- Searches Charting.dll for CStrategyObject strings.
- Scans readable private/mapped process memory for repeated pointers into Charting.dll.
- Ranks candidate vtable RVAs by object hit count.
- Reports mixed 0/1 byte offsets for candidate objects in range 0x000-0x2FF.
- Does not write MultiCharts memory or send UI input.
- Does not automatically accept any candidate as production-compatible.
