MCST-Watchdog 0.580 - Scheduled Reports and Heartbeat
=====================================================

- Added automatic scheduled status reports.
- Added configurable status report interval and optional send-on-startup.
- Added automatic heartbeat emails with the current Dashboard-based status report.
- Added configurable heartbeat interval and optional send-on-startup.
- Dashboard Status Reports and Heartbeat rows now show their real running state.
- Reload Settings resets scheduling safely and applies the new intervals without restarting.
- Scheduled reports are also saved to the configured report file.
- Existing AutoTrading alerts, recovery email, test email and manual report remain available.
- No Bridge V155 protocol changes.
