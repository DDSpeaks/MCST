MCST-Watchdog 0.580a - Architecture Cleanup and Build Fix
=========================================================

- Fixed the C2001 "newline in constant" build errors in main.cpp.
- Replaced broken multiline wide string literals with explicit CRLF sequences.
- Moved asynchronous email dispatch and its result type into Email.cpp / Email.h.
- Added AutoTradingAlertTracker in AlertService.cpp / AlertService.h.
- Added ScheduleTracker in ScheduleService.cpp / ScheduleService.h for scheduled reports and heartbeat timing.
- Simplified main.cpp so it coordinates services instead of containing their state machines.
- Reset alert and schedule state when settings are reloaded.
- Scheduled report file failures are now written to Recent Activity instead of being reported as success.
- Updated visible and INI version strings to 0.580a.
- No Bridge V155 protocol or verified AutoTrading reader changes.
