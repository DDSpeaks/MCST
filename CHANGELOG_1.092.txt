MCST-Watchdog 1.093 - Windows 10 Text Clarity
================================================

- Replaced the Windows 11-only "Segoe UI Variable Text" request with the native Windows 10 "Segoe UI" family.
- Kept all dashboard text on the Win32 GDI DrawText path with ClearType enabled.
- Added DPI-aware point-size font creation using negative logical font heights.
- Added a dedicated Segoe UI Semibold label font for monitoring row names.
- Retained regular-weight text for descriptions to preserve visual hierarchy.
- Darkened secondary and descriptive text colors for improved contrast over RDP.
- Preserved GDI+ only for status indicators; text is not rendered through GDI+.
- Updated visible, email-test and configuration version numbers to 1.093.
