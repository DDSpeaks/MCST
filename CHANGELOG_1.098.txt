MCST-Watchdog 1.098 - Status Report Wide Description Column

Changes
-------
- Widened the HTML Status Report description column substantially.
- Reduced the Component column from 205 px to 145 px.
- Reduced the Status column from 135 px to 100 px.
- Gave the Description column a 650 px target width.
- Increased the status table maximum width to 1180 px.
- Kept Component and Status values on one line while allowing descriptions to wrap only when necessary.
- Preserved the CSS status indicators and the mixed Segoe UI / monospace report typography introduced in 1.097.
- No changes to Bridge V155, AutoTrading, Broker Monitor, scheduling, or Compatibility Framework.
