MCST-Watchdog 1.099 - Status Report Unified Typography

Changes
-------
- Restored a single consistent monospaced typeface throughout the HTML Status Report.
- Removed the mixed Segoe UI / Consolas presentation introduced in 1.097.
- SYSTEM STATUS, OVERALL STATUS, headings, resource tables, accounts, positions and logs now use the same Consolas / Courier New fallback stack.
- Preserved the fixed HTML columns introduced in 1.097 and the wider Description column introduced in 1.098.
- Preserved CSS status indicators and their color coding.
- No monitoring, scheduling, broker, AutoTrading, Bridge or Compatibility logic was changed.
